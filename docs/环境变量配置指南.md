# 环境变量配置指南

本文档说明如何配置会议纪要系统所需的环境变量。

## 快速开始

1. **复制环境变量模板**
   ```bash
   cp .env.example .env
   ```

2. **编辑 `.env` 文件，填入真实配置值**

3. **确保 `.env` 文件不会被提交到 Git**（已在 `.gitignore` 中配置）

---

## 必需的环境变量

### 1. Kimi API 配置

用于调用大语言模型生成会议纪要。

```bash
KIMI_API_KEY=your-kimi-api-key-here
KIMI_BASE_URL=https://apie.zhisuaninfo.com/v1
KIMI_MODEL=GLM-5
```

**获取方式：**
- 访问 Kimi API 平台注册并获取 API Key
- 或使用其他兼容 OpenAI API 格式的大模型服务

### 2. HuggingFace Token

用于下载 pyannote 说话人分离模型。

```bash
HF_TOKEN=your-huggingface-token-here
```

**获取方式：**
1. 访问 https://huggingface.co/settings/tokens
2. 创建一个新的 Access Token（Read 权限即可）
3. 复制 token 到 `.env` 文件

### 3. JWT 密钥

用于用户认证和会话管理。

```bash
JWT_SECRET=your-random-secret-key-here
JWT_EXPIRATION=86400000
```

**建议：**
- 使用随机生成的强密钥，至少 32 位
- 可以使用在线工具生成：`openssl rand -base64 32`

## 可选的环境变量

### 数据库配置

如果使用自定义数据库配置：

```bash
DB_HOST=localhost
DB_PORT=3307
DB_NAME=meeting_record
DB_USERNAME=root
DB_PASSWORD=your_secure_password
```

### Redis 配置

```bash
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=
```

### 文件路径配置

```bash
# 上传文件存储路径
UPLOAD_PATH=./cache/uploads

# Python 解释器路径（留空使用系统默认）
PYTHON_PATH=python

# Whisper 转录脚本路径
WHISPER_SCRIPT_PATH=./backend/whisper/transcribe.py

# Whisper 模型大小
WHISPER_MODEL=base
```

### FFmpeg 和模型缓存

```bash
# FFmpeg 可执行文件目录（留空使用系统 PATH）
FFMPEG_PATH=

# Whisper 模型缓存目录
WHISPER_CACHE_DIR=

# HuggingFace 模型缓存目录
HF_HOME=
```

## 在 Spring Boot 中使用环境变量

项目的 `application.yml` 已配置为从环境变量读取配置：

```yaml
meeting:
  kimi:
    api-key: ${KIMI_API_KEY}
    base-url: ${KIMI_BASE_URL:https://apie.zhisuaninfo.com/v1}
    model: ${KIMI_MODEL:GLM-5}
```

语法说明：
- `${ENV_VAR}` - 从环境变量读取，如果未设置则报错
- `${ENV_VAR:default}` - 从环境变量读取，如果未设置则使用默认值

---

## 在 Python 脚本中使用环境变量

Python 脚本通过 `os.environ.get()` 读取环境变量：

```python
import os

# 读取 HuggingFace Token
hf_token = os.environ.get("HF_TOKEN", "")

# 读取模型缓存路径
whisper_cache = os.environ.get("WHISPER_CACHE_DIR", "")
```

## 验证配置

### 1. 检查环境变量是否生效

**Windows:**
```cmd
echo %KIMI_API_KEY%
echo %HF_TOKEN%
```

**Linux/macOS:**
```bash
echo $KIMI_API_KEY
echo $HF_TOKEN
```

### 2. 测试后端启动

```bash
cd backend
mvn spring-boot:run
```

查看日志，确认没有配置错误。

### 3. 测试 Python 脚本

```bash
cd backend/whisper
python download_pyannote.py
```

如果 `HF_TOKEN` 未设置，脚本会提示错误。

## 常见问题

### Q1: 环境变量不生效？

**Windows:**
- 使用 `set` 命令设置的环境变量只在当前命令行窗口有效
- 建议在项目根目录创建 `.env` 文件，并使用工具加载（如 `dotenv`）

**Linux/macOS:**
- 使用 `export` 命令设置的环境变量只在当前 shell 会话有效
- 建议将环境变量添加到 `~/.bashrc` 或 `~/.zshrc`

### Q2: 如何在 IDE 中配置环境变量？

**IntelliJ IDEA:**
1. Run → Edit Configurations
2. 选择 Spring Boot 启动配置
3. Environment variables 中添加配置

**VS Code:**
在 `.vscode/launch.json` 中添加：
```json
{
  "configurations": [
    {
      "env": {
        "KIMI_API_KEY": "your-key-here",
        "HF_TOKEN": "your-token-here"
      }
    }
  ]
}
```

### Q3: Docker 环境如何配置？

在 `docker-compose.yml` 中添加：
```yaml
services:
  backend:
    environment:
      - KIMI_API_KEY=${KIMI_API_KEY}
      - HF_TOKEN=${HF_TOKEN}
    env_file:
      - .env
```

## 安全建议

1. **永远不要将 `.env` 文件提交到 Git**
2. **定期轮换 API Key 和 Token**
3. **使用强随机密钥作为 JWT_SECRET**
4. **生产环境使用密钥管理服务**（如 AWS Secrets Manager、Azure Key Vault）
5. **限制 API Key 的权限和使用范围**
