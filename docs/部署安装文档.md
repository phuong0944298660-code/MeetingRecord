## 二、Windows 系统部署指南

### 步骤 1: 安装基础环境

#### 1.1 安装 Java 17
1. 访问 https://adoptium.net/
2. 下载 **Eclipse Temurin JDK 17** (Windows x64 MSI Installer)
3. 运行安装程序，按提示完成安装
4. 验证安装:
   ```cmd
   java -version
   # 应显示: openjdk version "17.0.x"
   ```

#### 1.2 安装 Maven
1. 访问 https://maven.apache.org/download.cgi
2. 下载 **apache-maven-3.9.x-bin.zip**
3. 解压到 `E:\AboutDevelopment\apache-maven-3.9.x`
4. 配置环境变量:
   - 新建系统变量 `MAVEN_HOME`: `E:\AboutDevelopment\apache-maven-3.9.x`
   - 编辑 `Path` 变量，添加: `%MAVEN_HOME%\bin`
5. 验证安装:
   ```cmd
   mvn -version
   ```

#### 1.3 安装 Node.js 18
1. 访问 https://nodejs.org/
2. 下载 **Node.js 18.x LTS** (Windows Installer)
3. 运行安装程序
4. 验证安装:
   ```cmd
   node -v
   npm -v
   ```
5. 配置npm缓存到E盘(可选):
   ```cmd
   npm config set cache "E:/AboutDevelopment/NPMCache"
   ```

#### 1.4 安装 Python 3.11
1. 访问 https://www.python.org/downloads/
2. 下载 **Python 3.11.x** (Windows installer 64-bit)
3. **安装时注意**: 勾选 "Add Python to PATH"
4. 验证安装:
   ```cmd
   python --version
   pip --version
   ```

#### 1.5 安装 FFmpeg
1. 访问 https://www.gyan.dev/ffmpeg/builds/
2. 下载 **ffmpeg-release-essentials.7z**
3. 解压到 `D:\App\Common\FFmpeg\ffmpeg-x.x-essentials_build`
4. 配置环境变量:
   - 编辑 `Path` 变量，添加: `D:\App\Common\FFmpeg\ffmpeg-x.x-essentials_build\bin`
5. 验证安装:
   ```cmd
   ffmpeg -version
   ```

#### 1.6 安装 Docker Desktop (可选)
1. 访问 https://www.docker.com/products/docker-desktop/
2. 下载并安装 Docker Desktop
3. 启动 Docker Desktop，等待提示 "Docker Desktop is running"
4. 验证安装:
   ```cmd
   docker --version
   docker-compose --version
   ```

### 步骤 2: 下载项目代码

```cmd
# 创建项目目录
mkdir D:\traeOwnProject
cd D:\traeOwnProject

# 克隆项目(假设使用git)
git clone https://github.com/your-repo/meeting-record.git
# 或者下载zip解压
cd meeting-record
```

### 步骤 3: 配置模型文件

#### 3.1 创建模型目录
```cmd
mkdir E:\Models\whisper
mkdir E:\Models\huggingface\hub
```

#### 3.2 安装Python依赖并下载模型
```cmd
cd backend\whisper

# 创建虚拟环境(推荐)
python -m venv venv
venv\Scripts\activate

# 安装依赖
pip install openai-whisper pyannote.audio librosa numpy torch torchaudio

# 下载Whisper模型
python -c "import whisper; whisper.load_model('base')"

# 下载pyannote模型(需要HF Token)
# 从 https://huggingface.co/settings/tokens 获取你的 token
set HF_TOKEN=your_huggingface_token_here
set HF_HOME=your_models_directory
python -c "from pyannote.audio import Pipeline; Pipeline.from_pretrained('pyannote/speaker-diarization-3.1')"
```

### 步骤 4: 配置数据库

#### 方案 A: 使用 Docker (推荐)
```cmd
cd D:\traeOwnProject\meeting-record

# 启动MySQL和Redis
docker-compose up -d mysql redis

# 验证状态
docker-compose ps
```

#### 方案 B: 本地安装 MySQL
1. 访问 https://dev.mysql.com/downloads/installer/
2. 下载 **MySQL Installer for Windows**
3. 选择 "Server only" 安装
4. 配置:
   - 端口: 3306
   - root密码: 123456
   - 创建数据库: meeting_record

### 步骤 5: 配置后端

#### 5.1 修改配置文件
编辑 `backend\src\main\resources\application.yml`:

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/meeting_record?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: 123456  # 修改为你的MySQL密码
    
  data:
    redis:
      host: localhost
      port: 6379

meeting:
  kimi:
    api-key: ${KIMI_API_KEY}  # 从环境变量读取
    base-url: ${KIMI_BASE_URL:https://apie.zhisuaninfo.com/v1}
    model: ${KIMI_MODEL:GLM-5}
  
  upload:
    path: ${UPLOAD_PATH:./cache/uploads}  # 从环境变量读取

whisper:
  pythonPath: ${PYTHON_PATH:python}  # 从环境变量读取
  scriptPath: ${WHISPER_SCRIPT_PATH:./backend/whisper/transcribe.py}
  model: ${WHISPER_MODEL:base}
```

#### 5.2 编译并运行后端
```cmd
cd backend

# 编译
mvn clean package -DskipTests

# 运行
mvn spring-boot:run

# 或使用JAR运行
java -jar target/meeting-record-backend-1.0.0.jar
```

后端服务将在 http://localhost:8080 启动

### 步骤 6: 配置前端

```cmd
cd frontend

# 安装依赖
npm install

# 开发模式运行
npm run dev

# 或构建生产版本
npm run build
```

前端将在 http://localhost:5173 启动

### 步骤 7: 验证部署

1. 访问 http://localhost:5173
2. 使用默认账号登录: admin/admin
3. 上传测试音频文件验证功能

## 三、macOS 系统部署指南

### 步骤 1: 安装 Homebrew

```bash
# 打开终端，运行
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 添加到PATH
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

### 步骤 2: 安装基础环境

#### 2.1 安装 Java 17
```bash
# 使用 Homebrew
brew install openjdk@17

# 创建符号链接
sudo ln -sfn /opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-17.jdk

# 添加到 ~/.zshrc
echo 'export PATH="/opt/homebrew/opt/openjdk@17/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# 验证
java -version
```

#### 2.2 安装 Maven
```bash

# 验证
```

```bash
# 添加到 ~/.zshrc
```

#### 2.4 安装 Python 3.11

## 六、常见问题

### Q1: Python依赖安装失败
**解决方案:**
```bash
# 升级pip
pip install --upgrade pip

# 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q2: Whisper模型下载慢
**解决方案:**
- 手动下载模型文件放置到对应目录
- 或使用镜像站

### Q3: GLM-5 API连接超时
**解决方案:**
- 确保网络连接稳定
- 检查VPN/代理设置
- 在application.yml中增加超时时间

### Q4: MySQL连接失败
**解决方案:**
```bash
# 检查MySQL服务状态
# Windows
net start mysql

# Mac
brew services list
brew services restart mysql
```
